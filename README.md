# QuickNotes

QuickNotes is a simple browser-based note-taking application that allows users to create, organise, search and delete notes. Notes can be assigned to Personal, Work or Study categories, and they are saved in the browser so they remain available after the page is refreshed.

## Features

- Add notes quickly and easily
- Categorise notes as Personal, Work or Study
- Display the date and time each note was created
- Delete individual notes
- Search notes in real time
- Validate notes before saving
- Limit notes to 200 characters
- Display the total number of saved notes
- Save notes using browser localStorage
- Responsive layout for smaller screens

## How to Run Locally

1. Clone the repository from GitHub.
2. Open the project folder in VS Code.
3. Open `index.html` in a web browser.
4. Start creating and managing your notes.

No external dependencies or installation are required.
